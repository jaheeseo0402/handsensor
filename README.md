# 핸드플레이 (HandPlay)

flex 센서 장갑으로 손동작을 인식해 OLED 러너 게임을 조작하는 프로토타입.
센서 값 5개를 AI 모델이 "어떤 손동작인가"로 분류하고, 그 결과가 게임 명령이 된다.

> 이번 단계의 목표는 **장갑이 서로 다른 손동작을 구분한다**를 보이는 것이다.
> 학습 데이터만 바꾸면 실제 재활 동작으로 교체할 수 있는 구조로 만든다.

## 시스템 구조

```
[사용 단계: 게임 중 (장갑 + 브레드보드)]
센서 장갑 ──▶ ESP32 ──▶ AI 모델 ──▶ OLED 게임
(flex 5개)   (값 읽기·필터)  (동작 3+1 분류)  (점프·슬라이드)
                              ▲
                              │ 모델 숫자 복사
[학습 단계: PC에서 한 번]      │
데이터 수집 ──▶ 학습·검증 ──▶ 모델 숫자
(동작별 센서 값)  (파이썬, 정확도)  (ESP32 코드에 삽입)
```

| 구분 | 내용 |
|---|---|
| 입력 | flex 센서 5개 (아날로그 값) |
| 출력 | 4클래스: 대기(손 펴기) + 동작 3개 |
| 모델 | kNN 또는 로지스틱 회귀 (PC 학습 → ESP32 탑재, 안 되면 PC 분류로 대체) |
| 게임 조작 | 동작 1 = 점프, 동작 2 = 슬라이드, 동작 3 = 이중점프 |

## 검증 지표

- 동작별 인식률
- 본인 vs 다른 사람 인식률 비교
- 고정 기준값 방식 vs 학습 방식 정확도 비교
- 자주 헷갈린 동작 쌍
- 동작 → 화면 반응 지연시간 (ms)
