# 설계 검토 (부품 주문 전)

원본 설계서 v1(2026.11.17) 기준 검토 사항. 처리되면 상태를 바꾼다.

| # | 항목 | 문제 | 제안 | 상태 |
|---|---|---|---|---|
| 1 | 센서 길이 | 4.5인치(약 11cm)는 엄지·새끼손가락에 너무 김 | 검지·중지·약지는 4.5인치, 엄지·새끼는 2.2인치 추가 구매 | 확인 필요 |
| 2 | 센서 고정 방향 | flex 센서는 핀이 나온 뿌리 쪽이 가장 잘 부러짐 | 뿌리는 손등 쪽(손가락 시작 관절 근처)에 고정하고 손끝 쪽이 미끄러지게. 설계서의 "첫 마디"가 이 의미인지 확인 | 확인 필요 |
| 3 | 전원 스위치 | 보조배터리를 ESP32 USB 포트에 꽂으면 브레드보드 스위치로 전원 차단 불가 | 배터리 전원을 VIN으로 따로 연결하거나, 스위치를 빼고 케이블 탈착으로 대체 | 확인 필요 |
| 4 | 보조배터리 자동 꺼짐 | 일부 보조배터리는 소전류 기기를 감지 못 하고 꺼짐 | 사용할 배터리로 미리 연속 동작 테스트 | 확인 필요 |
| 5 | GPIO 16, 17 | WROVER 모듈은 PSRAM이 이 핀을 사용 | WROOM 모듈 DevKit 구매 | 확인 필요 |
| 6 | 분압 저항 값 | 10kΩ가 센서 저항 범위에 맞지 않으면 해상도 손해 | 멀티미터로 펴짐/굽힘 저항 측정 후 그 사이 값으로 조정 (10kΩ로 시작 가능) | 측정 후 결정 |
| 7 | 버튼 개수 | 부품표 3개, 핀 표 2개로 불일치 | 용도 확정 후 통일 | 확인 필요 |
