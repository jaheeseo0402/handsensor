# 하드웨어

원본: [handplay-design-v1.pdf](handplay-design-v1.pdf). 수정이 필요한 항목은 [design-review.md](design-review.md) 참고.

장갑(손 부분)과 브레드보드 회로(화면 부분)로 나뉘고, 둘은 6선 커넥터로만 연결된다.

## 부품 목록

수량에는 납땜 실패와 센서 파손 대비 여분이 포함되어 있다.

### 손 부분 (장갑)

| 품목 | 수량 | 용도 |
|---|---|---|

## 회로

센서 1개당 분압 회로:

```
3.3V ── flex 센서 ──┬── 신호 (ESP32 ADC 핀)
                    │
                  10kΩ
                    │
                   GND
```

센서를 굽히면 저항이 커져 신호 전압이 내려가고, ESP32가 그 값을 읽는다.
저항은 브레드보드에 두므로 장갑 → 브레드보드 선은 **3.3V 공통 1선 + 신호 5선 = 6선**이다.

## 핀 배치 (예시, 구매한 보드에 맞춰 확정)

| 부품 | ESP32 핀 | 비고 |
|---|---|---|
| flex 센서 5개 | GPIO 32, 33, 34, 35, 36 | ADC1 (Wi-Fi 사용 시에도 읽기 가능) |
| OLED | SDA 21, SCL 22 | I2C 기준, SPI면 변경 |
| 버튼 | GPIO 25, 26 + GND | 내부 풀업 |
| LED | GPIO 16, 17 | 220Ω 거쳐 GND |
| 전원 | USB | 보조배터리 |

## 3D 프린팅 부품 (손 부분만)

장갑을 딱딱하게 덮지 않고, 얇고 납작하게 만들어 장갑 위에 꿰매 고정한다.

1. **뿌리 고정 클립**: 센서 뿌리 쪽 고정, 끝은 미끄러지게. 손가락당 1개, S/M/L 교체형.
2. **슬라이드 가이드 고리**: 센서가 손가락을 따라 미끄러지되 뜨지 않게. 손가락당 1~2개.
3. **손등 케이블 가이드**: 센서 선을 한 줄로 모아 손목 커넥터로.

### Tinkercad 모델링 순서

1. 손가락 폭, 센서 폭·두께를 재서 기록
2. 납작한 박스로 바닥판 (벽 1.5~2mm)
3. 센서 모양 Hole 도형으로 터널 (센서보다 0.2~0.3mm 여유)
4. 뿌리 클립에는 센서 끝이 멈추는 턱, 한쪽 끝은 개방
5. 실 구멍 2개 (꿰매서 고정)
6. 모서리 둥글게
7. 눕혀서 출력 (서포트 불필요)
8. 1개 먼저 출력해 맞춰 보고 복제, S/M/L은 폭만 변경

## 센서 값 안정화

- 여러 번 읽어 평균
- 값 스무딩
- 시작 시 캘리브레이션 (손 펴기 / 주먹으로 최소·최대 설정)
- 같은 동작이 연속으로 나올 때만 확정

## 시연 동작

| 항목 | 내용 |
|---|---|
| 대기 | 손 편 상태, 캐릭터는 계속 달림 |
| 동작 후보 | 주먹, 검지만 펴기, 가위(검지·중지), 새끼만 굽히기 |
| 확정 방법 | 센서 값을 찍어 보고 가장 잘 구분되는 3개 선택 |
| 규칙 | 동작이 바뀌는 순간에만 명령 실행, 게임 속도 느리게 |
| 제외 | 엄지 의존 동작 (값 불안정) |
